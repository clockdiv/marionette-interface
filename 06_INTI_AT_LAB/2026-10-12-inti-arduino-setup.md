
# Inti Arduino Setup

## project file
BNO055_MUX_DaisyChainAdapt_OSC.ino


## (if needed) install Rosetta for Arduino IDE
	$ softwareupdate --install-rosetta

### Board Manager URL for ESP32
https://espressif.github.io/arduino-esp32/package_esp32_index.json
Board to select: ESP32 Dev Module
Upload Speed:    115200
Hold down **BOOT** on ESP32 when uploading

### Libraries
*install directly form Arduino IDE*

- Adafruit BNO055 (by Adafruit)
- OSC (by Adrian Freed)
- Sparkfun I2C Mux Arduino Library (by SparkFun)
